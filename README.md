# 📄 AI Resume Parser

> **Developed as part of the Pinnacle Labs AI Internship**

An AI-powered Resume Parser built using **Python**, **Streamlit**, **Regex**, and **Natural Language Processing (NLP)** to automatically extract useful information from PDF resumes.

This project demonstrates practical applications of Artificial Intelligence in Human Resource (HR) automation by parsing resumes and extracting structured candidate information such as name, email, phone number, and technical skills.
